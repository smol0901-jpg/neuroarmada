# 🐯 Нейроармада

Модульная match-3 игра с тигрятами.

## Структура проекта

```
src/
├── core/           # Ядро игры
│   ├── board.js    # Управление полем
│   ├── game.js     # Главный цикл
│   ├── match.js    # Поиск совпадений
│   └── storage.js # Сохранение
├── systems/        # Игровые системы
│   └── audio/     # Звук
├── utils/          # Утилиты
│   ├── eventemitter.js
│   ├── tiger.js
│   └── input.js
└── main.js        # Точка входа
```

## Запуск

```bash
# Локально (нужен локальный сервер)
npx serve .

# Или через VS Code Live Server
```

## Деплой

Игра готова для Vercel, Netlify или GitHub Pages.

## Особенности

- Canvas-рендеринг
- Адаптивный UI для ПК и мобильных
- Модульная архитектура
- Система сохранения
- Звуковые эффекты
